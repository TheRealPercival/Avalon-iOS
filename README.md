# Avalon iOS

This is an online version of Don Eskridge's _Avalon: Big Box Edition_ for iPhone and iPad devices. It involves some house rules and features that make it different from the original game, but most of the original game mechanics are the same.

## Project Details

This frontend project is written as a native iOS app in Swift and uses the SwiftUI framework.

The main functionality of the app requires a deployment of the [Avalon backend server](https://github.com/TheRealPercival/Avalon-Server).
